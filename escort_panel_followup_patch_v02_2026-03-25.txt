Guild of Merchants 護衛パネル追補差分 v0.2
更新日: 2026-03-25
対象:
- ui/game_hud.gd

今回の修正意図
- 移動確認ダイアログが護衛パネル中央に被り続ける問題を緩和
- 護衛パネル表示中に背後MAPへ触れてしまう問題を解消

方針
- 移動確認ダイアログは最初から左寄せ配置にする
- 護衛パネル表示中は map_window 全体に透明ブロッカーを敷き、背後MAP入力を遮断する
- 透明ブロッカーの上に護衛パネルを置くので、MAPノード解除や背景クリックが起きなくなる

func _close_escort_confirm_if_any(restore_move_focus: bool = true) -> void:
    if is_instance_valid(_escort_confirm_dlg):
        _escort_confirm_dlg.queue_free()
    _escort_confirm_dlg = null

    if is_instance_valid(_escort_modal_blocker):
        _escort_modal_blocker.queue_free()
    _escort_modal_blocker = null

    _escort_offer_list = null
    _escort_offer_detail = null
    _escort_offer_summary = null
    _escort_toggle_btn = null
    _escort_depart_btn = null
    _escort_selected_offer_ids.clear()
    _escort_selected_offer_map.clear()
    _escort_offer_context.clear()

    _set_move_confirm_interactable(true)

    if restore_move_focus and is_instance_valid(_move_confirm_dlg):
        _move_confirm_dlg.show()
        _move_confirm_dlg.grab_focus()

func _ensure_escort_modal_blocker() -> void:
    if not is_instance_valid(map_window):
        return

    if is_instance_valid(_escort_modal_blocker):
        return

    var blocker := ColorRect.new()
    blocker.name = "EscortModalBlocker"
    blocker.color = Color(0, 0, 0, 0.001)
    blocker.anchor_left = 0.0
    blocker.anchor_top = 0.0
    blocker.anchor_right = 1.0
    blocker.anchor_bottom = 1.0
    blocker.offset_left = 0
    blocker.offset_top = 0
    blocker.offset_right = 0
    blocker.offset_bottom = 0
    blocker.mouse_filter = Control.MOUSE_FILTER_STOP
    blocker.focus_mode = Control.FOCUS_ALL
    blocker.z_index = 180
    map_window.add_child(blocker)
    blocker.grab_focus()
    _escort_modal_blocker = blocker

5) _on_map_city_picked(cid: String) の末尾付近だけ追記
================================================================================

既存のこの部分:

    dlg.grab_focus()

この直後へ追加:

    var view_size: Vector2i = map_window.get_visible_rect().size
    var dlg_size: Vector2i = dlg.size
    if dlg_size.x <= 0:
        dlg_size.x = 260
    if dlg_size.y <= 0:
        dlg_size.y = 300

    dlg.position = Vector2i(
        max(24, int(view_size.x * 0.08)),
        max(72, int(view_size.y * 0.18))
    )

これで移動確認ダイアログは最初から左寄りへ移動します。
中央の護衛パネルと被り続ける状態をかなり避けやすくなります。


================================================================================
6) 意図
================================================================================

- 今回は「移動確認を護衛パネルの背面に完全に回す」のではなく、
  まず視認性を崩している主因を消す方向です
- Godot の ConfirmationDialog は Window 系なので、Control ベースの護衛パネルより前に見えやすいです
- そのため今回は
  - 移動確認は左へ逃がす
  - 背後のMAPはブロックする
  の2点を優先しています

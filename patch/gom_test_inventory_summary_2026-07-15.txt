TEST INV（テスト所持品モード）実装概要
更新日: 2026-07-15

基準コミット
------------
2b996c8b7b0e36abd04b4d3c8f3cba69d8adfa23

実装内容
--------
・DBGパネルへ「TEST INV — テスト所持品」を追加
・任意商品の追加、数量指定、0化
・テストで増やした商品だけを積載量から除外
・商品は実際のplayer.cargoへ入り、契約納品・売却・持ち物表示で使用可能
・生鮮品のplayer.cargoとcargo_lotsを同期
・cargo_lotsのセーブ復元と旧セーブ互換再構成
・大切なものの所持状態をunique / max_stackに従って設定
・大切なものは自動効果を実行せず、所持条件だけを作成
・受注中契約の不足品を商品別に合算して補充
・テスト開始時のcargo、cargo_lots、key_items、capを復元可能
・所持品を残し、積載除外だけ終了する操作を追加
・TEST INVの操作を[TEST]付き行動ログへ記録
・DBG非表示時にTEST INVも非表示
・key_items.csvのcargo_cap_addをworld.gdで互換処理
・others/引継.txtを最新状態へ更新

重要な仕様
----------
・DEBUGビルド専用です。
・テスト付与品はセーブへ含まれます。
・積載除外と復元スナップショットはランタイム専用で、ロード後は解除されます。
・通常プレイ用とは別のセーブスロットを使用してください。
・通常プレイへ戻る前に「開始時へ復元」を使用してください。
・大切なもののテスト設定では自動効果を実行しません。

適用方法

git apply --check gom_test_inventory_patch_2026-07-15.txt
git apply gom_test_inventory_patch_2026-07-15.txt

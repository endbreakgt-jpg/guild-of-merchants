# 履歴資料（archive）

旧パッチ・テスト用データ案・検証ログを保存しています。**現行コードへ自動適用しないでください。**
過去の意図や不具合調査の経緯を確認する場合だけ参照します。

- `patches/completed/`：旧 `others/完了/` にあった適用済み・完了扱いの差分やデータ案
- `patches/2026-07-10/`：旧 `others/20260710/` のMAP/UI差分
- `patches/legacy_world_diff.txt`：旧 `others/差分.txt`
- `logs/prodlog3.txt` ～ `prodlog5.txt`：過去の生産ログ

本整理では、ファイルの論理的な移動を基本とし、バイナリPDFや原案本文は変更していません。
移動対象に含まれるCSVのGodot import設定のみ、旧ファイル位置参照を新パスへ更新しています。
